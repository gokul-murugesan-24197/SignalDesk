SignalDesk

★★★★★

Groups the same customer problem into one incident.

Many people write in about one outage. SignalDesk puts those tickets together and shows what to open first.

A simple day

18 people said “I cannot log in.” SignalDesk makes one incident for the Incident team and marks the urgent tickets.

An invoice ticket is a different problem. It stays separate.

Short use case

The booking page is down. Patients open many tickets that say the same thing.

The handler opens Start Here, not 18 separate tickets.

2. Add the new ticket as a child POST/api/v1/tickets/{parent_ticket_id}/associate 
type: child
ticketIds: [child ticket id]
Same department. One parent per child. Up to 200 children.
2. Mark Start Here, including a near ETA POST/api/v1/tickets/{ticket_id}/associateTag 
tags: ["start-here"]
Mark the ticket when any of these is true:
- priority is Urgent or High
- no agent reply yet
- SLA ETA is today or tomorrow
ETA can be the ticket due date, or a custom ETA set by the customer or the agent.

Set up in Zoho Desk

  • Turn on parent-child tickets for the department.
  • Create a team named Incident. Use it if you already have one.
  • Make two views: Open Incidents and Start Here.
  • Run EchoMark, DawnTally, and FirstBell at 7:00. Run NestPin when a ticket is created.

SignalDesk only reads and updates tickets in one department. It does not email the customer, and it does not close or delete tickets.
